# これは記録であって、計画ではありません

**ここにある文書は、すでに終わった作業の記録です。**
ファイル名に `plan` と付いていますが、**やることリストではありません。**

- 書かれている「フェーズ」は**全部済んでいます**
- 「決めていないこと」の節も、**その時点で**未定だったという記録です
- ここを読んで新しい作業を始めないでください

## 何のために残しているか

**なぜそう作ったかを残すため**です。コードを読めば何をしているかは分かりますが、
「他の選択肢をなぜ採らなかったか」「どこで測って、何が分かったか」は
書き残さないと消えます。
