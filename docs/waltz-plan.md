# 不均等な拍 (ウィンナ・ワルツ風) の計画

小節の中で**拍の長さ自体を変える**機能。基本は**中央の拍を山とする左右対称**で、
3拍子なら「**短・長・短**」——**2拍目が前に出る**形。5拍子なら
「短・中・長・中・短」、7拍子も同様に中央がいちばん長い。

小節の総和は変えないので、テンポとループ位置は動かない。

**山と谷の両方を1つのスライダーで扱う。** 中央が長い「山」がウィンナ風、
中央が短い「谷」はその裏返し。同じ式の符号違いなので、実装は1つで済む。

スウィング (`docs/swing-plan.md`) と並ぶ2つ目の「記譜は等分のまま、出力の
直前に揺らぎを乗せる」機能。ただし**中身の性質はかなり違う** (後述)。

## 確定した仕様

| 項目 | 内容 |
|---|---|
| 形 | 中央の拍を頂点とする左右対称。`d_i = (m + (R−1)k_i) / (m + (R−1)k̄)` |
| 強さ | スライダー `R` = **端の拍 ÷ 中央の拍**。`0.5..=2.0`、既定 **0.85** |
| 向き | **`R < 1` が山 (ウィンナ風)**、`R = 1` で無効、`R > 1` が谷 |
| 適用条件 | **奇数の N/4 (N≥3)** かつ トラックごとの ON/OFF |
| 変換 | **小節内の時間軸を区分線形に写像**。拍の中の音符も同じ比率で動く |
| 適用先 | 再生 / WAV / CCS / MIDI エクスポート のすべて |
| スウィングとの関係 | **併用可**。順序は **swing → ワルツ** で固定 |
| 保存 | `.ron` に `waltz_ratio` と トラックごとの `waltz` を追加 |

## 形の定義

拍数 `N` (奇数)、拍の番号 `i = 0..N-1`、中央 `m = (N−1)/2` とする。

- 中央からの距離 `k_i = |i − m|`
- その平均 `k̄ = m(m+1) / N`
- 拍の長さ (四分音符単位):

```
d_i = (m + (R−1)·k_i) / (m + (R−1)·k̄)
```

`R` は**端の拍と中央の拍の比**そのもの。`k_i = m` を入れると `mR/D`、
`k_i = 0` で `m/D` になり、割ると `R` に戻る。

この形にした理由。

- **`Σd_i = N` が厳密に成り立つ。** `Σk_i = N·k̄` なので分子の総和が
  `N(m + (R−1)k̄)` になり、分母で割ると `N`。**小節の長さは 1 tick も動かない**
- **`R = 1` が恒等になる。** すべての `d_i` が 1 になり、無効と等価。
  スウィングの `C` と同じ感覚で使える
- **`R > 0` である限り拍長が正。** 分子の最小値は `R<1` なら `k_i = m` で `mR`、
  `R>1` なら `k_i = 0` で `m`。どちらも正。分母も `k̄ < m` から正。
  **範囲外の値を渡されても拍が消えない**
- **意味が拍子に依らない。** 「いちばん短い拍はいちばん長い拍の何倍か」は
  3/4 でも 7/4 でも同じ読み方ができる

### 具体値 (既定 `R = 0.85`、山)

| 拍子 | 拍の長さ (四分音符) |
|---|---|
| 3/4 | **0.9444** / 1.1111 / **0.9444** |
| 5/4 | 0.9341 / 1.0165 / **1.0989** / 1.0165 / 0.9341 |
| 7/4 | 0.9297 / 0.9844 / 1.0391 / **1.0938** / 1.0391 / 0.9844 / 0.9297 |

拍頭の位置 (3/4): `0 / 0.9444 / 2.0556 / 3`。
**2拍目が 0.0556拍 早まり、3拍目が同じだけ遅れる。** 180BPM なら約 18.5ms。

### 両側の比較 (3/4)

| `R` | 形 | 拍の長さ | 2拍目の位置 |
|---|---|---|---|
| 0.5 | 山 (強) | 0.75 / 1.50 / 0.75 | 0.750 (**−0.250**) |
| **0.85** (既定) | 山 | 0.9444 / 1.1111 / 0.9444 | 0.9444 (**−0.0556**) |
| 1.0 | — | 1 / 1 / 1 | 1.000 (無効) |
| 1.1765 | 谷 | 1.0526 / 0.8947 / 1.0526 | 1.0526 (+0.0526) |
| 2.0 | 谷 (強) | 1.2 / 0.6 / 1.2 | 1.200 (+0.200) |

`R` と `1/R` は**比としては裏返しだが、拍長そのものは鏡像にならない**
(総和を `N` に保つ正規化のぶんずれる)。テストでもそこは区別する。

**既定値と範囲は実測で決める。** スウィングのように典拠となる論文を持って
いないので、**耳で決めた値であることを明示して置く**。まず `0.5..=2.0` /
既定 `0.85` で鳴らして詰める。

## 変換の設計

小節内の時間軸を**区分線形に写像**する。拍 `i` の区間 `[i, i+1)` を
`[o_i, o_i + d_i)` へ移す (`o_i = Σ_{j<i} d_j`)。

```rust
/// 記譜上の位置 (四分音符) を、演奏上の位置へ写す。
pub fn map(tick: f32, beats: u32, ratio: f32) -> f32
```

拍頭かどうかを見ない。**位置がどの拍の中にあるかだけ**で決まるので、
8分・16分・連符・どんな端数も自動で拍と一緒に伸縮する。

### スウィングとの違い

スウィングは**位置ベース** (拍頭と裏拍だけを動かし、他は据え置く)。
ワルツは**時間軸ごとの写像**。この違いから、**スウィングで手当てが要った
副作用3点が原理的に起きない**。

| スウィングの副作用 | ワルツでは |
|---|---|
| (a) 音価が負になりうる | **起きない。** 写像が狭義単調なので `end > start` が保たれる |
| (b) ノートの順序が入れ替わりうる | **起きない。** 同じ理由 |
| (c) 最後のノートが終端をはみ出す | **起きない。** 小節線は不動点 (`map(kN) = kN`) |

前のノートの終端と次のノートの開始に同じ値が乗る点はスウィングと同じなので、
**重なりも隙間も生じない**。

### 併用の順序: swing → ワルツ

**この順序でなければならない。** スウィングの判定は
`tick.rem_euclid(1.0)` が 0 か 0.5 かを見る位置ベースなので、**先にワルツを
掛けると位置が整数・半整数から外れ、スウィングが何にも当たらなくなる**。

```
記譜位置 ──swing::offset──> スウィング後 ──waltz::map──> 演奏位置
```

副作用として、**スウィングの遅れは拍の伸縮率のぶん拡大・縮小される**。
`R = 0.85` の 3/4 なら、長い中央の拍では遅れが約1.11倍、短い端の拍では
約0.94倍になる。**拍に対する割合として一定**になるので、これは望ましい挙動
として受け入れる。

スウィングは小節線を越える位置 (3/4 なら 3.098) を作りうるが、`map` は
`floor(tick / N)` で小節を求めるため次の小節の1拍目として正しく扱われる。
既存の「終端を小節境界で頭打ち」も小節線が不動点なのでそのまま効く。

### `performed_notes` の再構成

現在は `swing::applies_to` で早期に抜けている。2つの機能が独立に効くので、
**シフト関数を組み立ててから流す**形に変える。

```rust
pub fn performed_notes(&self) -> Vec<Note> {
    // どちらも無効なら記譜のまま返す (今と同じ)
    // トラックごとに swing / waltz の有無を見て shift を合成する
}
```

`shift` の合成以外 (音価0の扱い、最小音価、終端の頭打ち) は現状のまま使う。

## UI

- **強さのスライダー**: ツールバーのスウィングの隣。**1.0 が中央で無効**、
  左へ動かすと山 (ウィンナ風)、右へ動かすと谷。どちら向きかが分かる
  ラベルを添える (例: `← 2拍目が前 / 後ろ →`)
- **トラックごとの ON/OFF**: 左のトラック欄に `M` `S` `W` と並べて `V` を足す
  (`W` はスウィングが使っている。ウィンナ = Vienna の `V`)
- 奇数の N/4 以外では、スウィングと同じくトグルを無効化して理由を出す

## `.ron` への追加

```ron
(
    version: 1,
    swing_peak_ratio: 1.5,
    waltz_ratio: 0.85,
    tracks: [
        (name: "トラック 1", ..., swing: false, waltz: false),
    ],
)
```

**`version` は 1 のまま。** 「未知のフィールドは無視、欠けたフィールドは
`#[serde(default)]` で埋める」という既存方針の通りで、古い `.ron` はそのまま
開けるし、新しい `.ron` を古いビルドで開いても壊れない。検証は
`waltz_ratio` を範囲に丸めるだけ (**0 以下を弾くのが要点**)。

## フェーズ分け

| フェーズ | 内容 | 状態 |
|---|---|---|
| **1** | `waltz.rs` (形の計算と時間軸の写像) と単体テスト | **完了** |
| **2** | `performed_notes` の再構成、`TrackInfo.waltz`、`MidiEditor.waltz_ratio`。4つの出力すべてに乗る | **完了** |
| **3** | UI (スライダー、トラックのトグル、ヘルプ、guide.md、README) | **完了** |
| **4** | `.ron` の保存・読み込み・検証 | **完了** |

### フェーズ3で分かったこと (ツールバーの幅)

**スライダーを1行目に足したら、幅が足りずに右端で切れた。** 1366px の窓で
「拍の偏り」のラベルだけが出て、スライダーと数値が画面外に落ちた。

**スウィングと拍の偏りを2行目にまとめて解決した。** ラベルを短くする手もあるが、
それでは項目が1つ増えるたびに同じことが起きる。**`swing-plan.md` のフェーズ3で
一度踏んでいて、これで2度目**なので、幅の取り合いそのものから外した。

「ラベルとスライダーは折り返しの直接の子にする」(`add_enabled_ui` や `scope` で
包まない) という前回の教訓は、そのまま守れば足りた。

### フェーズ2で分かったこと (フェーズ4が前倒しになる)

**`TrackInfo` にフィールドを足した時点で `.ron` も直さないとコンパイルが通らない。**
保存形式をフェーズ4に分けていたが、実際にはフェーズ2と同時に入った
(テストだけ後から足した)。モデルに触る変更は保存形式と切り離せない。

### 副作用が本当に起きないこと

計画で「区分線形なら起きない」とした3点は、実装後も**手当てが一切要らなかった**。
64分音符でも音価は負にならず、小節線ちょうどで終わるノートも伸びない。
`performed_notes` の下限と頭打ちはスウィングのために残してあるだけで、
ワルツ単独では素通りする。

## テスト計画

**形の性質**

- `Σd_i == N` が N = 3/5/7/9 と **山・谷の両側**の `R` で成り立つこと
- `R < 1` で中央が最長、`R > 1` で中央が最短になること (向きの取り違え防止)
- 中央から端へ向かって狭義単調であること
- `d_端 / d_中央 == R` になること (スライダーの意味が保たれること)
- `R = 1.0` がすべての位置で恒等写像になること (無効と等価)
- **`R` と `1/R` で長短が入れ替わること。ただし拍長は鏡像にならないこと**
- 範囲外の `R` (0 以下、極端に大きい値) を渡しても拍長が正であること

**写像の性質 (重なり回避の核心)**

- 狭義単調であること (多数の位置を並べて確かめる)
- 小節線が不動点であること (`map(0) == 0`、`map(N) == N`、`map(2N) == 2N`)
- 拍頭が `o_i` に一致すること
- 拍の中の連符が**拍の中で等分のまま**であること (拍ごと伸縮するので比は保たれる)
- 前のノートの終端と次のノートの開始が一致し続けること
- **64分音符でも音価が負にならないこと** (スウィングとの対比。ここは回帰しやすい)

**適用条件**

- 3/4・5/4・7/4 で適用、4/4・6/4 で無適用、3/8 で無適用、1/4 で無適用
- `waltz` が偽のトラックが1 tick も動かないこと

**スウィングとの併用**

- 順序が swing → ワルツ であること (先にワルツを掛けた場合と結果が異なることを固定)
- 併用時もノートが連続し続けること
- 片方だけ ON のトラックが互いに影響しないこと

**`.ron`**

- 往復で `waltz_ratio` とトラックの `waltz` が保たれること
- **`waltz_*` を持たない古い `.ron` が既定値で開けること**
- 範囲外の `waltz_ratio` が丸められること (**`0.0` や負の値を含む**)

## 未決・割り切り

- **強さは耳で決める。** スウィングは論文に基づく曲線を持っているが、
  こちらは典拠が無い。既定 `0.85` と範囲 `0.5..=2.0` は**実機で確認して据え置いた**
  が、あくまで耳で決めた値。文献に当たるなら、拍の実測値を扱った演奏分析が要る
- **テンポ依存は入れない。** まず一定で作り、必要なら後から曲線を足す。
  スウィングの `ratio()` が前例になる
- 強さは全体設定、ON/OFF はトラックごと (スウィングと同じ)。トラックごとに
  移すのは `#[serde(default)]` のおかげで1フィールドで済む
- 偶数拍子は対象外。谷 (山) を中央2拍の間に置く定義を足せば拡張できるが、
  判定は `applies_to` 1箇所に閉じ込めておく
- MIDI エクスポートにも乗るので、書き出した MIDI を読み戻すと二重に掛かる。
  保存は `.ron` で行うのでスウィングと同じく許容する
